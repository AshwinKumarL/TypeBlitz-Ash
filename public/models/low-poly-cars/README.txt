What is inside
--------------
- 12 GLB files (binary glTF 2.0), one vehicle each, plus a preview image of each in previews/.
- Sizes are in metres. +Y is up, the front faces +Z, the origin is on the ground under the middle.
- Nodes: Body, Wheel_FL, Wheel_FR, Wheel_RL, Wheel_RR. Spin a wheel on its X axis to roll forward.
- Materials have plain names (Paint, Glass, Trim, Tyre, Rim, Headlight, Taillight...).
  Change the colour of "Paint" to recolour a car. No textures.

How to use
----------
three.js: GLTFLoader. Unity: the glTFast package (com.unity.cloud.gltfast). Godot 4: drop the .glb in the
FileSystem dock. Blender: File > Import > glTF 2.0, and export to FBX, OBJ or STL from there if you need to.

More free models: https://vinish.dev/free-3d-models/
